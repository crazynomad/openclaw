# 第三集：消息的奇幻旅程

> 🎬 **本集看点**：跟着一条 WhatsApp 消息，走完它的一生！从"你好"到 AI 回复"你好呀~"，中间发生了什么？

---

## 🎬 开场：一条消息的诞生

```
┌─────────────────────────────────────────────────────────────────────┐
│                                                                     │
│    📱 用户小明的手机                                                 │
│    ┌─────────────────────────────────┐                             │
│    │  WhatsApp                       │                             │
│    │  ─────────────────────────────  │                             │
│    │                                 │                             │
│    │  🤖 AI 助手                      │                             │
│    │                                 │                             │
│    │  小明：今天天气怎么样？          │  ← 消息诞生！                │
│    │                          [发送] │                             │
│    │                                 │                             │
│    └─────────────────────────────────┘                             │
│                                                                     │
│    这条消息接下来会经历怎样的奇幻旅程？                               │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

---

## 🗺️ 旅程全景图

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                                                                             │
│  📱 小明手机                    🖥️ OpenClaw 服务器              ☁️ AI 云端   │
│                                                                             │
│  ┌─────────┐    ①    ┌─────────────────────────────────┐    ⑤    ┌──────┐ │
│  │ WhatsApp │───────→│  WhatsApp Channel (Baileys)      │───────→│Claude│ │
│  │   App   │         │         ↓ ②                      │        │  AI  │ │
│  └─────────┘         │  ┌─────────────────────────────┐ │        └──┬───┘ │
│       ↑              │  │      Gateway (网关)          │ │           │     │
│       │              │  │         ↓ ③                  │ │    ⑥     │     │
│       │              │  │  ┌───────────────────────┐  │ │◄──────────┘     │
│       │              │  │  │   Agent (智能体)      │  │ │                 │
│       │              │  │  │       ↓ ④             │  │ │                 │
│       │              │  │  │   Session (会话)      │  │ │                 │
│       │    ⑧         │  │  └───────────────────────┘  │ │                 │
│       │◄─────────────│  │         ↓ ⑦                  │ │                 │
│       │              │  │  WhatsApp Channel (发送)     │ │                 │
│       │              │  └─────────────────────────────┘ │                 │
│  收到回复！           └─────────────────────────────────────┘                 │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘

步骤说明：
① 消息从 WhatsApp 发出
② Channel 接收并解析消息
③ Gateway 路由到正确的 Agent
④ Agent 加载 Session（历史对话）
⑤ 调用 AI API
⑥ AI 返回响应
⑦ 通过 Channel 发送回复
⑧ 用户收到消息
```

## 📍 第一站：Channel 接收消息

消息首先到达 WhatsApp Channel（基于 Baileys 库）：

```
┌─────────────────────────────────────────────────────────────────────┐
│  📍 第一站：WhatsApp Channel                                         │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│  原始消息（WhatsApp 格式）：                                          │
│  {                                                                  │
│    "key": {                                                         │
│      "remoteJid": "8613800138000@s.whatsapp.net",                   │
│      "fromMe": false,                                               │
│      "id": "3EB0A0B3C..."                                           │
│    },                                                               │
│    "message": {                                                     │
│      "conversation": "今天天气怎么样？"                               │
│    }                                                                │
│  }                                                                  │
│                                                                     │
│                           ↓ 转换为统一格式                            │
│                                                                     │
│  OpenClaw 内部格式：                                                 │
│  {                                                                  │
│    "channel": "whatsapp",                                           │
│    "sender": "+8613800138000",                                      │
│    "text": "今天天气怎么样？",                                        │
│    "isGroup": false,                                                │
│    "timestamp": 1699999999                                          │
│  }                                                                  │
│                                                                     │
│  💡 这就是适配器模式的威力！不管什么平台，都变成统一格式               │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

**关键代码位置**：`src/web/channel.ts`

## 📍 第二站：Gateway 路由

Gateway 收到消息后，要决定：这条消息该交给哪个 Agent 处理？

```
┌─────────────────────────────────────────────────────────────────────┐
│  📍 第二站：Gateway 路由决策                                          │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│  ┌─────────────────────────────────────────────────────────────┐   │
│  │                    Gateway 的内心戏                          │   │
│  │                                                             │   │
│  │  🤔 "收到一条来自 WhatsApp 的消息..."                        │   │
│  │                                                             │   │
│  │  检查清单：                                                  │   │
│  │  ✅ 1. 这个发送者在白名单里吗？                              │   │
│  │  ✅ 2. 应该用哪个 Agent 处理？                               │   │
│  │  ✅ 3. 有没有正在进行的会话？                                │   │
│  │                                                             │   │
│  │  决定：交给 "main" Agent，会话 ID 是 "whatsapp:138xxx"       │   │
│  │                                                             │   │
│  └─────────────────────────────────────────────────────────────┘   │
│                                                                     │
│                                                                     │
│  路由规则示意：                                                      │
│                                                                     │
│  ┌─────────┐     ┌──────────────────┐     ┌─────────────┐         │
│  │  消息   │────→│  allowFrom 检查  │────→│  Agent 路由  │         │
│  │  进入   │     │  (白名单/黑名单)  │     │  (配置匹配)  │         │
│  └─────────┘     └──────────────────┘     └──────┬──────┘         │
│                         │                        │                 │
│                         ▼                        ▼                 │
│                    ❌ 拒绝                  ┌─────────────┐        │
│                    (无权限)                 │ Agent: main │        │
│                                            └─────────────┘        │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

**关键代码位置**：`src/gateway/server-chat.ts`，`src/routing/`

│  │     │     │       │            │                            │   │
│  │     │     │       │            └── 用户标识                  │   │
│  │     │     │       └── 渠道                                  │   │

│  │                                                             │   │
│  └─────────────────────────────────────────────────────────────┘   │
│                                                                     │
│                                                                     │
│  Session 内容（存在 ~/.openclaw/sessions/）：                        │
│                                                                     │

## 📍 第四站：Agent 执行

现在，Agent 要调用 AI 了！

```
┌─────────────────────────────────────────────────────────────────────┐
│  📍 第四站：Agent 调用 AI                                            │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│  Agent 有两种执行模式：                                              │
│                                                                     │
│  ┌─────────────────────────────────────────────────────────────┐   │
│  │                                                             │   │
│  │  模式 A：Embedded Pi（内嵌模式）                             │   │
│  │  ─────────────────────────────────                          │   │
│  │  直接调用 Anthropic SDK                                     │   │
│  │                                                             │   │
│  │  OpenClaw ──→ Anthropic SDK ──→ Claude API                  │   │
│  │                                                             │   │
│  │  优点：简单、低延迟                                          │   │
│  │  场景：使用 Claude 模型                                      │   │
│  │                                                             │   │
│  └─────────────────────────────────────────────────────────────┘   │
│                                                                     │
│  ┌─────────────────────────────────────────────────────────────┐   │
│  │                                                             │   │
│  │  模式 B：CLI Runner（命令行模式）                            │   │
│  │  ─────────────────────────────────                          │   │
│  │  调用外部 CLI 工具                                          │   │
│  │                                                             │   │
│  │  OpenClaw ──→ 子进程 ──→ claude-cli / other                 │   │
│  │                                                             │   │
│  │  优点：灵活、可扩展                                          │   │
│  │  场景：使用其他模型或自定义后端                              │   │
│  │                                                             │   │
│  └─────────────────────────────────────────────────────────────┘   │
│                                                                     │
│                                                                     │
│  API 调用示意（以 Claude 为例）：                                    │
│                                                                     │
│  请求：                                                             │
│  {                                                                  │
│    "model": "claude-sonnet-4-20250514",                            │
│    "messages": [                                                    │
│      {"role": "user", "content": "你好"},                          │
│      {"role": "assistant", "content": "你好！有什么可以帮你的？"},  │
│      {"role": "user", "content": "今天天气怎么样？"}                │
│    ],                                                               │
│    "system": "你是一个友好的 AI 助手..."                            │
│  }                                                                  │
│                                                                     │
│  响应：                                                             │
│  {                                                                  │
│    "content": "我无法直接获取实时天气信息，但你可以..."            │
│  }                                                                  │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

**关键代码位置**：`src/agents/pi-embedded.ts`，`src/commands/agent.ts`

## 📍 第五站：响应回传

AI 的回复需要原路返回给用户：

```
┌─────────────────────────────────────────────────────────────────────┐
│  📍 第五站：响应投递                                                  │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│  AI 响应："我无法直接获取实时天气信息，但你可以查看天气预报网站，    │
│           或者告诉我你在哪个城市，我可以给你一些建议。"              │
│                                                                     │
│                           ↓                                         │
│                                                                     │
│  ┌─────────────────────────────────────────────────────────────┐   │
│  │                    消息分块处理                              │   │
│  │                                                             │   │
│  │  为什么要分块？                                              │   │
│  │  • WhatsApp 限制：4000 字符                                  │   │
│  │  • Telegram 限制：4000 字符                                  │   │
│  │  • Discord 限制：2000 字符                                   │   │
│  │                                                             │   │
│  │  如果 AI 回复超长，自动拆分成多条消息！                       │   │
│  │                                                             │   │
│  └─────────────────────────────────────────────────────────────┘   │
│                                                                     │
│                           ↓                                         │
│                                                                     │
│  ┌─────────────────────────────────────────────────────────────┐   │
│  │                    通过 Channel 发送                         │   │
│  │                                                             │   │
│  │  channel.outbound.sendText({                                │   │
│  │    target: "+8613800138000",                                │   │
│  │    text: "我无法直接获取实时天气信息..."                     │   │
│  │  })                                                         │   │
│  │                                                             │   │
│  │                      ↓                                      │   │
│  │                                                             │   │
│  │  Baileys SDK (WhatsApp) 发送消息                            │   │
│  │                                                             │   │
│  └─────────────────────────────────────────────────────────────┘   │
│                                                                     │
│                           ↓                                         │
│                                                                     │
│  📱 小明的手机收到消息！                                             │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

**关键代码位置**：`src/infra/outbound/deliver.ts`
