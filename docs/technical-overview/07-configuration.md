# 第七集：配置系统 - 一切尽在掌控

> 🎬 **本集看点**：一个 JSON 文件，掌控整个 AI 助手帝国！

---

## 📁 配置文件在哪？

```
┌─────────────────────────────────────────────────────────────────────┐
│                                                                     │
│                    📁 配置文件位置                                   │
│                                                                     │
│   ~/.openclaw/                                                      │
│   ├── openclaw.json       ← 🎯 主配置文件（本集主角）               │
│   ├── credentials/        ← 🔐 认证凭据（API Keys 等）              │
│   ├── sessions/           ← 💾 会话数据                             │
│   └── agents/             ← 🤖 Agent 运行时数据                     │
│       └── <agentId>/                                                │
│           └── sessions/                                             │
│                                                                     │
│   也可以用环境变量指定：                                             │
│   OPENCLAW_CONFIG=/path/to/custom/config.json                       │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

## 🤖 agents 配置详解

```
┌─────────────────────────────────────────────────────────────────────┐
│                                                                     │
│                      🤖 agents 配置                                 │
│                                                                     │
│   {                                                                 │
│     "agents": {                                                     │
│                                                                     │
│       // 📋 Agent 列表                                              │
│       "list": [                                                     │
│         {                                                           │
│           "id": "main",                    // Agent 标识符          │
│           "model": "claude-sonnet-4-...",  // 使用的模型            │
│           "systemPrompt": "你是一个友好的助手...",  // 人设         │
│           "skills": ["search", "code"],    // 启用的技能            │
│           "workspace": "~/projects"        // 工作目录              │
│         },                                                          │
│         {                                                           │
│           "id": "coder",                                            │
│           "model": "claude-opus-4-...",                            │
│           "systemPrompt": "你是一个编程专家...",                    │
│           "skills": ["code", "file"]                               │
│         }                                                           │
│       ],                                                            │
│                                                                     │
│       // 🎯 默认配置                                                │
│       "defaults": {                                                 │
│         "id": "main"    // 默认使用哪个 Agent                       │
│       }                                                             │
│     }                                                               │
│   }                                                                 │
│                                                                     │
│   使用场景：                                                        │
│   ┌─────────────────────────────────────────────────────────────┐  │
│   │                                                             │  │
│   │   • main    → 日常对话（默认）                              │  │
│   │   • coder   → 写代码（@coder 或路由配置指定）               │  │
│   │   • writer  → 写文章                                        │  │
│   │   • ...                                                     │  │
│   │                                                             │  │
│   └─────────────────────────────────────────────────────────────┘  │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

## 🔐 allowFrom：访问控制

谁可以跟你的 AI 聊天？

```
┌─────────────────────────────────────────────────────────────────────┐
│                                                                     │
│                      🔐 allowFrom 配置                              │
│                                                                     │
│   "allowFrom" 决定谁有权限与 AI 对话                                │
│                                                                     │
│   ┌─────────────────────────────────────────────────────────────┐  │
│   │                                                             │  │
│   │   // 1️⃣ 允许所有人（开放模式）                               │  │
│   │   "allowFrom": ["*"]                                        │  │
│   │                                                             │  │
│   │   // 2️⃣ 只允许特定用户（白名单模式）                         │  │
│   │   "allowFrom": [                                            │  │
│   │     "+8613800138000",      // 手机号（WhatsApp/Signal）     │  │
│   │     "123456789",           // 用户 ID（Telegram/Discord）   │  │
│   │     "@username"            // 用户名                        │  │
│   │   ]                                                         │  │
│   │                                                             │  │
│   │   // 3️⃣ 允许特定群组                                        │  │
│   │   "allowFrom": [                                            │  │
│   │     "group:123456789"      // 群组 ID                       │  │
│   │   ]                                                         │  │
│   │                                                             │  │
│   │   // 4️⃣ 混合模式                                            │  │
│   │   "allowFrom": [                                            │  │
│   │     "+8613800138000",      // 特定用户                      │  │
│   │     "group:*"              // 所有群组                      │  │
│   │   ]                                                         │  │
│   │                                                             │  │
│   └─────────────────────────────────────────────────────────────┘  │
│                                                                     │
│   💡 安全建议：                                                     │
│   • 开发测试时可以用 "*"                                            │
│   • 生产环境强烈建议使用白名单                                      │
│   • API 调用要花钱，别让陌生人白嫖！                                │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

## 🎛️ gateway 配置详解

```
┌─────────────────────────────────────────────────────────────────────┐
│                                                                     │
│                      🎛️ gateway 配置                                │
│                                                                     │
│   {                                                                 │
│     "gateway": {                                                    │
│                                                                     │
│       // 🌐 网络配置                                                │
│       "bind": "loopback",        // loopback | lan | all           │
│       "port": 18789,             // 端口号                          │
│                                                                     │
│       // 🔐 认证配置                                                │
│       "auth": {                                                     │
│         "password": "your-secret-password",  // 密码认证           │
│         // 或者使用 Token                                          │
│         "tokens": [                                                 │
│           {                                                         │
│             "token": "abc123...",                                   │
│             "scope": ["admin", "read", "write"]                    │
│           }                                                         │
│         ]                                                           │
│       },                                                            │
│                                                                     │
│       // ☁️ 远程访问（可选）                                        │
│       "remote": {                                                   │
│         "enabled": true,                                            │
│         "url": "wss://your-server.com/ws"                          │
│       }                                                             │
│                                                                     │
│     }                                                               │
│   }                                                                 │
│                                                                     │
│   bind 选项说明：                                                    │
│   ┌───────────┬────────────────────────────────────────────────┐   │
│   │ loopback  │ 只允许本机访问（最安全）                        │   │
│   ├───────────┼────────────────────────────────────────────────┤   │
│   │ lan       │ 允许局域网访问                                  │   │
│   ├───────────┼────────────────────────────────────────────────┤   │
│   │ all       │ 允许任何来源（需要配合防火墙）                   │   │
│   └───────────┴────────────────────────────────────────────────┘   │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

## ✅ Zod 验证：配置也有类型检查

```
┌─────────────────────────────────────────────────────────────────────┐
│                                                                     │
│                    ✅ 配置验证 = 运行时类型检查                      │
│                                                                     │
│   OpenClaw 使用 Zod 库在运行时验证配置：                             │
│                                                                     │
│   ┌─────────────────────────────────────────────────────────────┐  │
│   │                                                             │  │
│   │   // 写错了？马上告诉你！                                    │  │
│   │                                                             │  │
│   │   {                                                         │  │
│   │     "gateway": {                                            │  │
│   │       "port": "18789"    // ❌ 应该是数字，不是字符串！      │  │
│   │     }                                                       │  │
│   │   }                                                         │  │
│   │                                                             │  │
│   │   Error: Expected number, received string at "gateway.port" │  │
│   │                                                             │  │
│   └─────────────────────────────────────────────────────────────┘  │
│                                                                     │
│   好处：                                                            │
│   ✅ 启动时就发现错误（不是运行到一半才崩）                          │
│   ✅ 错误信息清晰（告诉你哪里错了）                                  │
│   ✅ 自动补全默认值（没写的用默认值）                                │
│                                                                     │
│   源码位置：src/config/zod-schema.*.ts                              │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

## 🔄 热重载：改配置不用重启

```
┌─────────────────────────────────────────────────────────────────────┐
│                                                                     │
│                    🔄 配置热重载                                     │
│                                                                     │
│   修改 openclaw.json 后：                                           │
│                                                                     │
│   方式 1: Gateway 自动检测                                          │
│   ─────────────────────────                                        │
│   Gateway 会监听配置文件变化，自动重载                               │
│   （部分配置需要重启才生效）                                         │
│                                                                     │
│   方式 2: CLI 手动触发                                              │
│   ─────────────────────                                            │
│   $ openclaw config reload                                          │
│                                                                     │
│   方式 3: RPC 调用                                                  │
│   ────────────────                                                 │
│   调用 config.reload() 方法                                         │
│                                                                     │
│                                                                     │
│   哪些配置支持热重载？                                               │
│   ┌───────────────────────────┬─────────────────────────────────┐  │
│   │  ✅ 支持热重载            │  ❌ 需要重启                      │  │
│   ├───────────────────────────┼─────────────────────────────────┤  │
│   │  • allowFrom 白名单       │  • gateway.port 端口             │  │
│   │  • agent systemPrompt     │  • gateway.bind 绑定地址         │  │
│   │  • 部分渠道配置            │  • 新增/删除渠道                  │  │
│   └───────────────────────────┴─────────────────────────────────┘  │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```
