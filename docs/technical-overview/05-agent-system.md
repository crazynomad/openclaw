# 第五集：Agent 智能体 - AI 的灵魂

> 🎬 **本集看点**：Agent 是 OpenClaw 的大脑！看看它是怎么思考、记忆、行动的。

---

## 🧠 什么是 Agent？

先来一个灵魂比喻：

```
┌─────────────────────────────────────────────────────────────────────┐
│                                                                     │
│                       🧠 Agent = 你的 AI 分身                       │
│                                                                     │
│   想象你雇了一个超级助理：                                            │
│                                                                     │
│   ┌─────────────────────────────────────────────────────────────┐  │
│   │                                                             │  │
│   │   📥 输入                    🧠 处理                 📤 输出  │  │
│   │                                                             │  │
│   │   "帮我订明天                理解意图                "好的，  │  │
│   │    飞北京的机票"    →        查询信息       →        已为您   │  │
│   │                              做出决策                 预订..." │  │
│   │                              执行操作                         │  │
│   │                                                             │  │
│   └─────────────────────────────────────────────────────────────┘  │
│                                                                     │
│   这个助理需要：                                                     │
│   ✅ 理解你说的话（自然语言理解）                                    │
│   ✅ 记住之前聊过什么（会话记忆）                                    │
│   ✅ 知道自己能做什么（工具能力）                                    │
│   ✅ 做出合理的回应（推理决策）                                      │
│                                                                     │
│   Agent 就是这个 AI 助理的软件实现！                                 │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

## 💾 Session：AI 的记忆系统

没有记忆的 AI 是金鱼 🐟，有记忆的 AI 才是助理！

```
┌─────────────────────────────────────────────────────────────────────┐
│                                                                     │
│                    💾 Session = AI 的记忆                           │
│                                                                     │
│   没有 Session 的对话：                                              │
│   ┌─────────────────────────────────────────────────────────────┐  │
│   │                                                             │  │
│   │   用户：我叫小明                                             │  │
│   │   AI：你好小明！                                             │  │
│   │                                                             │  │
│   │   用户：我叫什么？                                           │  │
│   │   AI：抱歉，我不知道你叫什么 😵                              │  │
│   │                                                             │  │
│   └─────────────────────────────────────────────────────────────┘  │
│                                                                     │
│   有 Session 的对话：                                               │
│   ┌─────────────────────────────────────────────────────────────┐  │
│   │                                                             │  │
│   │   用户：我叫小明                                             │  │
│   │   AI：你好小明！                                             │  │
│   │                           ↓ 保存到 Session                   │  │
│   │   用户：我叫什么？                                           │  │
│   │   AI：你叫小明呀！        ← 从 Session 读取                  │  │
│   │                                                             │  │
│   └─────────────────────────────────────────────────────────────┘  │
│                                                                     │
│                                                                     │
│   Session 存储格式：                                                 │
│   ┌─────────────────────────────────────────────────────────────┐  │
│   │                                                             │  │
│   │   Session Key: agent:main:whatsapp:+8613800138000           │  │
│   │   ──────────────────────────────────────────────────────    │  │
│   │                                                             │  │
│   │   {                                                         │  │
│   │     "messages": [                                           │  │
│   │       {"role": "user", "content": "我叫小明"},              │  │
│   │       {"role": "assistant", "content": "你好小明！"},       │  │

│   │       {"role": "assistant", "content": "你叫小明呀！"}      │  │
│   │     ]                                                       │  │
│   │   }                                                         │  │
│   │                                                             │  │
│   │   存储位置：~/.openclaw/sessions/                           │  │
│   │                                                             │  │
│   └─────────────────────────────────────────────────────────────┘  │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

## 🔧 工具系统：AI 的双手

AI 光会说不会做，那就是"嘴强王者"。工具让 AI 能够行动！

```
┌─────────────────────────────────────────────────────────────────────┐
│                                                                     │
│                      🔧 Agent Tools = AI 的双手                     │
│                                                                     │
│   ┌─────────────────────────────────────────────────────────────┐  │
│   │                                                             │  │
│   │   用户："帮我给老王发条消息，问他明天有空吗"                  │  │
│   │                                                             │  │
│   │                    AI 的思考过程                             │  │
│   │                    ───────────────                          │  │
│   │                           │                                 │  │
│   │                           ▼                                 │  │
│   │   ┌─────────────────────────────────────────────────────┐  │  │
│   │   │  🧠 "我需要发送消息..."                              │  │  │
│   │   │                                                     │  │  │
│   │   │  检查可用工具：                                      │  │  │
│   │   │  ✅ send_message - 可以发送消息！                    │  │  │
│   │   │  ❌ search_web - 不需要                             │  │  │
│   │   │  ❌ read_file - 不需要                              │  │  │
│   │   │                                                     │  │  │
│   │   │  决定调用：send_message                             │  │  │
│   │   │  参数：{                                            │  │  │
│   │   │    "target": "老王",                                │  │  │
│   │   │    "text": "明天有空吗？"                           │  │  │
│   │   │  }                                                  │  │  │
│   │   └─────────────────────────────────────────────────────┘  │  │
│   │                           │                                 │  │
│   │                           ▼                                 │  │
│   │   ┌─────────────────────────────────────────────────────┐  │  │
│   │   │  🔧 执行工具调用                                     │  │  │
│   │   │                                                     │  │  │
│   │   │  Gateway 收到工具调用请求                            │  │  │
│   │   │       ↓                                             │  │  │
│   │   │  找到老王的联系方式                                  │  │  │
│   │   │       ↓                                             │  │  │
│   │   │  通过 WhatsApp Channel 发送消息                      │  │  │
│   │   │       ↓                                             │  │  │
│   │   │  返回结果：{"success": true}                        │  │  │
│   │   └─────────────────────────────────────────────────────┘  │  │
│   │                           │                                 │  │
│   │                           ▼                                 │  │
│   │                                                             │  │
│   │   AI："好的，我已经给老王发送消息了，问他明天有没有空。"     │  │
│   │                                                             │  │
│   └─────────────────────────────────────────────────────────────┘  │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

## ⚡ 执行模式：两种大脑

Agent 有两种执行模式，就像两种不同的"大脑接入方式"：

```
┌─────────────────────────────────────────────────────────────────────┐
│                                                                     │
│                    ⚡ Agent 的两种执行模式                           │
│                                                                     │
│  ┌─────────────────────────────────────────────────────────────┐   │
│  │                                                             │   │
│  │   模式 A：Embedded Pi（内嵌模式）🧬                          │   │
│  │   ───────────────────────────────                           │   │
│  │                                                             │   │
│  │   OpenClaw ──直接调用──→ Anthropic SDK ──→ Claude API       │   │
│  │                                                             │   │
│  │   特点：                                                    │   │
│  │   ✅ 低延迟（少一层中转）                                   │   │
│  │   ✅ 简单直接                                               │   │
│  │   ✅ 支持流式输出                                           │   │
│  │   ⚠️ 仅支持 Claude 模型                                    │   │
│  │                                                             │   │
│  │   适用场景：默认模式，使用 Claude 时推荐                     │   │
│  │                                                             │   │
│  └─────────────────────────────────────────────────────────────┘   │
│                                                                     │
│  ┌─────────────────────────────────────────────────────────────┐   │
│  │                                                             │   │
│  │   模式 B：CLI Runner（命令行模式）🔌                         │   │
│  │   ─────────────────────────────────                         │   │
│  │                                                             │   │
│  │   OpenClaw ──子进程──→ claude-cli / other ──→ 各种 AI API   │   │
│  │                                                             │   │
│  │   特点：                                                    │   │
│  │   ✅ 灵活（支持任何 CLI 工具）                              │   │
│  │   ✅ 可扩展（换模型只需换 CLI）                             │   │
│  │   ⚠️ 略有延迟（多一层子进程）                              │   │
│  │                                                             │   │
│  │   适用场景：使用非 Claude 模型，或需要特殊 CLI 功能         │   │
│  │                                                             │   │
│  └─────────────────────────────────────────────────────────────┘   │
│                                                                     │
│  选择哪个？                                                         │
│  ┌─────────────────────────────────────────────────────────────┐   │
│  │                                                             │   │
│  │   想用 Claude？     ──→  Embedded Pi（默认，推荐）           │   │
│  │   想用 GPT-4？      ──→  CLI Runner + OpenAI CLI            │   │
│  │   想用本地模型？    ──→  CLI Runner + Ollama                │   │
│  │   想自定义？        ──→  CLI Runner + 你的 CLI              │   │
│  │                                                             │   │
│  └─────────────────────────────────────────────────────────────┘   │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

## 🎭 多 Agent 架构

一个 OpenClaw 可以有多个 Agent！

```
┌─────────────────────────────────────────────────────────────────────┐
│                                                                     │
│                     🎭 多 Agent 场景                                 │
│                                                                     │
│   为什么需要多个 Agent？                                             │
│                                                                     │
│   ┌─────────────────────────────────────────────────────────────┐  │
│   │                                                             │  │
│   │   Agent: main（默认）                                       │  │
│   │   ─────────────────                                        │  │
│   │   人设：通用助理                                            │  │
│   │   模型：claude-sonnet                                       │  │
│   │   用途：日常对话                                            │  │
│   │                                                             │  │
│   │   ─────────────────────────────────────────────────────    │  │
│   │                                                             │  │
│   │   Agent: coder                                              │  │
│   │   ──────────────                                           │  │
│   │   人设：编程专家                                            │  │
│   │   模型：claude-opus                                         │  │
│   │   工具：execute_code, read_file, write_file                │  │
│   │   用途：写代码、debug                                       │  │
│   │                                                             │  │
│   │   ─────────────────────────────────────────────────────    │  │
│   │                                                             │  │
│   │   Agent: translator                                         │  │
│   │   ─────────────────                                        │  │
│   │   人设：翻译专家                                            │  │
│   │   模型：claude-haiku（快）                                  │  │
│   │   用途：快速翻译                                            │  │
│   │                                                             │  │
│   └─────────────────────────────────────────────────────────────┘  │
│                                                                     │
│   配置示例：                                                        │
│   {                                                                 │
│     "agents": {                                                     │
│       "list": [                                                     │
│         {"id": "main", "model": "claude-sonnet-4-..."},            │
│         {"id": "coder", "model": "claude-opus-4-..."},             │
│         {"id": "translator", "model": "claude-3-haiku-..."}        │
│       ],                                                            │
│       "defaults": {"id": "main"}                                    │
│     }                                                               │
│   }                                                                 │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```
