│  ┌─────────────────────────────────────────────────────────────┐   │
│  │                                                             │   │
│  │  1️⃣  Channel Plugin（渠道插件）📱                            │   │
│  │      "新增一个聊天平台"                                       │   │
│  │      例：Telegram, Discord, Matrix, MS Teams                │   │
│  │                                                             │   │
│  │  ─────────────────────────────────────────────────────────  │   │
│  │                                                             │   │
│  │  2️⃣  Tool Plugin（工具插件）🔧                               │   │
│  │      "给 AI 新增一个能力"                                     │   │
│  │      例：网页搜索, 代码执行, 图片生成                         │   │
│  │                                                             │   │
│  │  ─────────────────────────────────────────────────────────  │   │
│  │                                                             │   │
│  │  3️⃣  Hook Plugin（钩子插件）🪝                               │   │
│  │      "在某个时机执行自定义逻辑"                               │   │
│  │      例：消息发送前加水印, 回复后记日志                       │   │
│  │                                                             │   │
│  │  ─────────────────────────────────────────────────────────  │   │
│  │                                                             │   │
│  │  4️⃣  Provider Plugin（提供者插件）☁️                         │   │

│  │                                                             │   │

## 🏗️ Plugin Registry：插件管理中心

所有插件都要在 Registry 注册才能生效：

```
┌─────────────────────────────────────────────────────────────────────┐
│                                                                     │
│                   🏗️ Plugin Registry 工作原理                       │
│                                                                     │
│   ┌─────────────────────────────────────────────────────────────┐  │
│   │                                                             │  │
│   │                     Plugin Registry                         │  │
│   │                     (全局注册中心)                           │  │
│   │                                                             │  │
│   │   ┌─────────────────────────────────────────────────────┐  │  │
│   │   │                    channels: Map                     │  │  │
│   │   │  ├── telegram  → TelegramPlugin                     │  │  │
│   │   │  ├── discord   → DiscordPlugin                      │  │  │
│   │   │  ├── whatsapp  → WhatsAppPlugin                     │  │  │
│   │   │  └── ...                                            │  │  │
│   │   └─────────────────────────────────────────────────────┘  │  │
│   │                                                             │  │
│   │   ┌─────────────────────────────────────────────────────┐  │  │
│   │   │                     tools: Map                       │  │  │
│   │   │  ├── send_message → SendMessageTool                 │  │  │
│   │   │  ├── search_web   → SearchWebTool                   │  │  │
│   │   │  └── ...                                            │  │  │
│   │   └─────────────────────────────────────────────────────┘  │  │
│   │                                                             │  │
│   │   ┌─────────────────────────────────────────────────────┐  │  │
│   │   │                     hooks: Map                       │  │  │
│   │   │  ├── onMessage    → [Hook1, Hook2, ...]             │  │  │
│   │   │  ├── onReply      → [Hook3, ...]                    │  │  │
│   │   │  └── ...                                            │  │  │
│   │   └─────────────────────────────────────────────────────┘  │  │
│   │                                                             │  │
│   └─────────────────────────────────────────────────────────────┘  │
│                                                                     │
│   注册流程：                                                        │
│                                                                     │
│   1. 插件加载      registry.register(myPlugin)                     │
│         │                                                          │
│         ▼                                                          │
│   2. 类型检测      "这是什么类型的插件？"                            │
│         │                                                          │
│         ▼                                                          │
│   3. 存入 Map      channels.set("my-channel", plugin)              │
│         │                                                          │
│         ▼                                                          │
│   4. 可被调用      getChannel("my-channel") → plugin               │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

## 🛠️ 开发一个 Channel Plugin

用一个简化的例子来说明：

```
┌─────────────────────────────────────────────────────────────────────┐
│                                                                     │
│            🛠️ 实战：开发一个 "Echo" Channel Plugin                  │
│                                                                     │
│   这是一个最简单的插件，收到什么就回复什么（用于测试）                 │
│                                                                     │
│   ┌─────────────────────────────────────────────────────────────┐  │
│   │                                                             │  │
│   │   // extensions/echo/src/channel.ts                        │  │
│   │                                                             │  │
│   │   import type { ChannelPlugin } from 'openclaw/plugin-sdk'; │  │
│   │                                                             │  │
│   │   export const echoPlugin: ChannelPlugin = {                │  │
│   │                                                             │  │
│   │     // 1️⃣ 基本信息                                          │  │
│   │     id: 'echo',                                             │  │
│   │     meta: {                                                 │  │
│   │       label: 'Echo Channel',                                │  │
│   │       description: '一个用于测试的回声渠道',                  │  │
│   │     },                                                      │  │
│   │                                                             │  │
│   │     // 2️⃣ 能力声明                                          │  │
│   │     capabilities: {                                         │  │
│   │       supportsText: true,                                   │  │
│   │       supportsMedia: false,                                 │  │
│   │       supportsGroups: false,                                │  │
│   │     },                                                      │  │
│   │                                                             │  │
│   │     // 3️⃣ 配置适配器                                        │  │
│   │     config: {                                               │  │
│   │       listAccounts: () => ['default'],                      │  │
│   │       resolveAccount: (id) => ({ id, enabled: true }),      │  │
│   │     },                                                      │  │
│   │                                                             │  │
│   │     // 4️⃣ 发送消息                                          │  │
│   │     outbound: {                                             │  │
│   │       sendText: async ({ target, text }) => {               │  │
│   │         console.log(`[Echo] → ${target}: ${text}`);         │  │
│   │         return { success: true };                           │  │
│   │       },                                                    │  │
│   │     },                                                      │  │
│   │                                                             │  │
│   │     // 5️⃣ 接收消息（Gateway 适配器）                         │  │
│   │     gateway: {                                              │  │
│   │       start: async (ctx) => {                               │  │
│   │         // 启动时的初始化逻辑                                │  │
│   │         console.log('[Echo] Gateway started');              │  │
│   │       },                                                    │  │
│   │       stop: async () => {                                   │  │
│   │         console.log('[Echo] Gateway stopped');              │  │
│   │       },                                                    │  │
│   │     },                                                      │  │
│   │                                                             │  │
│   │   };                                                        │  │
│   │                                                             │  │
│   └─────────────────────────────────────────────────────────────┘  │
│                                                                     │
│   然后在 package.json 中声明：                                      │
│   {                                                                 │
│     "name": "@openclaw/plugin-echo",                               │
│     "openclaw": {                                                   │
│       "type": "channel",                                            │
│       "entry": "./src/channel.ts"                                   │
│     }                                                               │
│   }                                                                 │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

## 🔌 Plugin SDK：开发者接口

OpenClaw 提供了完整的 SDK 供插件开发者使用：

```
┌─────────────────────────────────────────────────────────────────────┐
│                                                                     │
│                    🔌 Plugin SDK 导出一览                           │
│                                                                     │
│   import {                                                          │
│                                                                     │
│     // 类型定义                                                     │
│     ChannelPlugin,          // 渠道插件接口                         │
│     ChannelCapabilities,    // 渠道能力声明                         │
│     ChannelOutboundAdapter, // 发送消息适配器                       │
│     ChannelGatewayAdapter,  // 接收消息适配器                       │
│                                                                     │
│     // 配置相关                                                     │
│     OpenClawConfig,         // 全局配置类型                         │
│     buildChannelConfigSchema, // 构建配置 Schema                    │
│                                                                     │
│     // 工具函数                                                     │
│     normalizeE164,          // 手机号标准化                         │
│     formatDocsLink,         // 生成文档链接                         │
│     stringEnum,             // 类型安全的枚举                       │
│                                                                     │
│     // 消息处理                                                     │
│     resolveToolsBySender,   // 按发送者解析工具                     │
│     createTypingCallbacks,  // 创建"正在输入"回调                   │
│                                                                     │
│   } from 'openclaw/plugin-sdk';                                     │
│                                                                     │
│   文件位置：src/plugin-sdk/index.ts                                 │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```
