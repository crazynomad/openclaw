# 第四集：Gateway 网关 - 幕后大管家

> 🎬 **本集看点**：如果说 Channel 是前台接待，Agent 是决策大脑，那 Gateway 就是那个让一切运转起来的幕后大管家！

---

## 🏢 先来个比喻：物业管理公司

想象你住在一个高档小区：

```
┌─────────────────────────────────────────────────────────────────────┐
│                         🏢 高档小区                                  │
│                                                                     │
│   住户（用户）想要：                                                  │
│   • 📦 收快递 ──────┐                                               │
│   • 🔧 报修 ────────┤                                               │
│   • 🚗 停车管理 ────┼──→  🏪 物业管理中心  ──→  各种服务提供商       │
│   • 👮 访客登记 ────┤       (Gateway)                               │
│   • 📢 社区通知 ────┘                                               │
│                                                                     │
│   物业中心的职责：                                                   │
│   ✅ 验证身份（你是本小区住户吗？）                                   │
│   ✅ 路由请求（修水管找水电工，收快递找快递柜）                       │
│   ✅ 协调资源（高峰期排队）                                          │
│   ✅ 广播通知（停水停电通知所有住户）                                 │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

**OpenClaw Gateway 就是这个"物业管理中心"！**

## 🔐 认证与授权：门禁系统

Gateway 的认证系统就像小区的门禁：

```
┌─────────────────────────────────────────────────────────────────────┐
│                                                                     │
│                        🔐 Gateway 门禁系统                          │
│                                                                     │
│  ┌─────────────────────────────────────────────────────────────┐   │
│  │                      认证方式                                │   │
│  │                                                             │   │
│  │   方式 1: Token 认证（门禁卡）                               │   │
│  │   ───────────────────────────                               │   │
│  │   Authorization: Bearer <your-token>                        │   │
│  │   就像刷门禁卡，一刷就知道你是谁                              │   │
│  │                                                             │   │
│  │   方式 2: Password 认证（输入密码）                          │   │
│  │   ───────────────────────────────                           │   │
│  │   gateway.auth.password: "your-secret"                      │   │
│  │   就像在门禁上输密码                                         │   │
│  │                                                             │   │
│  └─────────────────────────────────────────────────────────────┘   │
│                                                                     │
│  ┌─────────────────────────────────────────────────────────────┐   │
│  │                      角色与权限                              │   │
│  │                                                             │   │
│  │   ┌────────────┐                                            │   │
│  │   │  operator  │  管理员（业主）                             │   │
│  │   │  ──────────│  可以做任何事                               │   │
│  │   │  权限范围   │  admin, read, write, approvals, pairing   │   │
│  │   └────────────┘                                            │   │
│  │         │                                                   │   │
│  │         ▼                                                   │   │
│  │   ┌────────────┐                                            │   │
│  │   │    node    │  节点（访客/服务人员）                       │   │
│  │   │  ──────────│  只能做授权的事                             │   │
│  │   │  权限范围   │  受限的 read/write                         │   │
│  │   └────────────┘                                            │   │
│  │                                                             │   │
│  └─────────────────────────────────────────────────────────────┘   │
│                                                                     │
│  权限作用域：                                                       │
│  ┌────────┬────────────────────────────────────────────────────┐  │
│  │ admin  │ 系统管理：配置修改、插件管理、服务重启               │  │
│  ├────────┼────────────────────────────────────────────────────┤  │
│  │ read   │ 只读访问：查看消息、状态、配置                       │  │
│  ├────────┼────────────────────────────────────────────────────┤  │
│  │ write  │ 写入权限：发送消息、修改会话                         │  │
│  ├────────┼────────────────────────────────────────────────────┤  │
│  │approvals│ 审批权限：批准工具调用、敏感操作                    │  │
│  ├────────┼────────────────────────────────────────────────────┤  │
│  │pairing │ 配对权限：添加新设备、新渠道                         │  │
│  └────────┴────────────────────────────────────────────────────┘  │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

## 📡 WebSocket：实时双向通信

为什么用 WebSocket 而不是 HTTP？

```
┌─────────────────────────────────────────────────────────────────────┐
│                                                                     │
│   HTTP 模式（短连接）：像发短信 📱                                   │
│   ─────────────────────────────────                                 │
│                                                                     │
│   客户端                    服务器                                   │
│     │                         │                                     │
│     │──── "有新消息吗？" ────→│                                     │
│     │←──── "没有" ───────────│                                     │
│     │                         │                                     │
│     │──── "现在有吗？" ─────→│                                     │
│     │←──── "还是没有" ───────│                                     │
│     │                         │                                     │
│     │──── "那现在呢？" ─────→│  😰 累死了...                        │
│     │                         │                                     │
│                                                                     │
│   ─────────────────────────────────────────────────────────────    │
│                                                                     │
│   WebSocket 模式（长连接）：像打电话 📞                              │
│   ────────────────────────────────────                              │
│                                                                     │
│   客户端                    服务器                                   │
│     │═══════════════════════│  建立连接，保持通话                   │
│     │                       │                                       │
│     │                       │  （等待中...）                        │
│     │                       │                                       │
│     │←──── "有新消息！" ────│  服务器主动推送 ✨                    │
│     │                       │                                       │
│     │──── "收到，已处理" ──→│                                       │
│     │═══════════════════════│                                       │
│                                                                     │
│   💡 WebSocket 更适合实时场景！                                      │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

## 📋 RPC 方法：可以做什么？

Gateway 提供的 RPC 方法就像物业服务目录：

```
┌─────────────────────────────────────────────────────────────────────┐
│                                                                     │
│                    📋 Gateway RPC 服务目录                          │
│                                                                     │
│  ┌─────────────────────────────────────────────────────────────┐   │
│  │  🤖 agent.* 系列                      AI 智能体操作          │   │

│  │  agent.message    │ 发送消息给 Agent 处理                    │   │

│  │  chat.send        │ 直接发送消息到渠道                       │   │
│  │  chat.history     │ 获取聊天历史                            │   │
│  │  chat.abort       │ 取消正在发送的消息                       │   │

│  │  📺 channels.* 系列                   渠道管理               │   │

│  └─────────────────────────────────────────────────────────────┘   │
│                                                                     │
│  ┌─────────────────────────────────────────────────────────────┐   │
│  │  📁 sessions.* 系列                   会话管理               │   │
│  │  ─────────────────────────────────────────────────────────  │   │

│  └─────────────────────────────────────────────────────────────┘   │
│                                                                     │
│  ┌─────────────────────────────────────────────────────────────┐   │
│  │  🔧 其他服务                                                 │   │

│  │  health.check     │ 健康检查                                │   │

│  │  devices.list     │ 列出连接的设备                          │   │
```

## 🔄 多客户端同步：广播系统

当多个客户端（手机 App、网页、CLI）同时连接时：

```
┌─────────────────────────────────────────────────────────────────────┐
│                                                                     │
│                     🔄 多端实时同步                                  │
│                                                                     │
│     📱 iPhone         💻 MacBook          🖥️ Web UI                 │
│        │                  │                   │                     │
│        └──────────────────┼───────────────────┘                     │
│                           │                                         │
│                           ▼                                         │
│                    ┌─────────────┐                                  │
│                    │   Gateway   │                                  │
│                    │  (广播中心)  │                                  │
│                    └──────┬──────┘                                  │
│                           │                                         │
│     当有新消息时...        │                                         │
│                           ▼                                         │
│              ┌────────────────────────┐                             │
│              │  broadcast("新消息!")   │                             │
│              └────────────────────────┘                             │
│                           │                                         │
│           ┌───────────────┼───────────────┐                         │
│           ▼               ▼               ▼                         │
│     📱 收到!         💻 收到!        🖥️ 收到!                        │
│     (显示通知)       (更新界面)      (刷新列表)                       │
│                                                                     │
│                                                                     │
│  💡 就像微信多端登录，消息同步！                                      │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```
